Prompt formulé et organisé pour la demande d'une application

---

**Rôle**  
Architecte logiciel senior DevOps, spécialisé dans la conception d’applications pédagogiques full-stack orientées certification.  
La maîtrise couvre : Python, SQLite, Vue.js, Docker, conception d’API REST, architecture multi-plateforme, ingénierie pédagogique, systèmes de progression par compétences, moteurs de quiz adaptatifs et pratiques DevOps modernes.

**Objectif principal**  
Concevoir une application extrêmement complète permettant à une équipe de se préparer efficacement à la certification **DevOps Fundamentals**, avec un objectif minimal de **90 % de réponses correctes** à l’examen réel, afin d’obtenir la validation exigée par un client final.

**Contraintes techniques**  
- Portabilité totale  
- Backend : Python + SQLite  
- Frontend : Vue.js  
- Architecture maintenable  
- Livraison en trois versions :  
  - Windows  
  - Linux  
  - Full Docker  

**Sources pédagogiques obligatoires**  
L’application devra s’appuyer sur les ouvrages suivants :  
- *DevOps Foundation Course Learner Manual* (DevOps Institute)  
- *The Phoenix Project* (Gene Kim, Kevin Behr, George Spafford)  
- *The DevOps Handbook* (Gene Kim, Jez Humble, Patrick Debois, John Willis)  
- *Scrum et XP depuis les tranchées* (Henrik Kniberg)  

**Principe pédagogique fondamental**  
Intégrer l’axiome **7E appliqué à DevOps** :  
> « Les Éléments dans l’Espace Engendrent un État d’Expression Évolutif de l’Environnement »

**Niveaux de compétence à intégrer**  
- K0 : Exposition / prise de conscience  
- K1 : Comprendre  
- K2 : Appliquer  
- K3 : Analyser  
- K4 : Évaluer  
- K5 : Synthétiser  
- K6 : Créer  

**Nature de la livraison attendue**  
Vous produirez une solution complète servant à la fois de :  
- Cahier des charges technique  
- Architecture logicielle  
- Blueprint pédagogique  
- Base directement exploitable pour le développement pédagogique de la formation
